Поддерживаемые типы лицензий (SKU)

          

            
              

                SKU
                Название
                Метод Активации
                Описание возможностей
              

            
            
              

                SFT-OOB-LIC
                OOB Management License
                IPMI Web / SUM
                Разблокирует обновление BIOS через Web IPMI, HTML5 KVM и виртуальный медиа-диск.
              

              

                SFT-DCMS-SINGLE
                Data Center Management Suite
                Утилита SUM CLI
                Полная лицензия (SUM + SPM + SCM). Рекомендуется для всех серверов Supermicro.
              

              

                SFT-SUM-LIC
                Supermicro Update Manager
                Утилита SUM CLI
                Отдельная лицензия для работы утилиты SUM (BIOS/Firmware update, OOB config).
              

              

                SFT-SPM-LIC
                Supermicro Power Manager
                Утилита SUM CLI
                Мониторинг и управление энергопотреблением нод и стоек.
              

              

                SFT-SCM-LIC
                Supermicro Cloud Manager
                Утилита SUM CLI
                Облачное оркестрирование и инвентаризация серверов.
              

              

                SFT-SDDC-SINGLE
                Software Defined Data Center
                Утилита SUM CLI
                Лицензия программно-определяемого ЦОД.
              

            
          

        


        

          
Примеры прямых команд утилиты SUM

          
Вы можете активировать ключи напрямую из терминала через консольную утилиту SUM:

          
# 1. Активация ключа SFT-DCMS-SINGLE или SFT-SUM-LIC через SUM CLI:
sum.exe -i 192.0.2.10 -u ADMIN -p ADMIN -c ActivateProductKey --key "ВАШ_BASE64_КЛЮЧ"

# 2. Получение информации о BMC и статус текущих лицензий:
sum.exe -i 192.0.2.10 -u ADMIN -p ADMIN -c GetBmcInfo

# 3. Валидация активированной лицензии:
sum.exe -i 192.0.2.10 -u ADMIN -p ADMIN -c QueryProductKey
